# ADR-0001 — Distribution: notarized DMG, hardened runtime, no sandbox, no MAS, no auto-update

**Status:** Accepted  
**Date:** 2026-05-01

> Carried over from the Swift predecessor. whisper.cpp is now statically linked via `whisper-rs`, so the library-validation row below no longer applies. The rest of the decision stands.

## Context

RAGNA Voice v1 needs a distribution strategy. The app requires microphone access, embeds whisper.cpp, and must run as a menu-bar-only agent (`LSUIElement`). The options considered were:

- Mac App Store (sandboxed)
- Mac App Store (with entitlements)
- Developer ID + notarized DMG
- Direct download, unsigned

## Decision

Distribute v1 as a **notarized DMG** signed with a **Developer ID Application** certificate, with **hardened runtime** enabled and **no App Sandbox**.

## Rationale

| Criterion | MAS | Developer ID DMG |
|---|---|---|
| Microphone via `device.audio-input` | requires sandbox | no sandbox required |
| Loading unsigned/third-party whisper.framework | forbidden | allowed with `cs.disable-library-validation` |
| `LSUIElement` menu-bar-only | allowed | allowed |
| Review queue latency for patches | days–weeks | instant |
| Gatekeeper trust on fresh Mac | automatic | requires notarization |
| 30 % revenue cut | yes | no |

The `com.apple.security.app-sandbox` entitlement is deliberately absent. Sandbox would require a separate XPC helper process for microphone capture and complicate the whisper.cpp embedding — an engineering cost that is not justified for v1.

## Consequences

- Maintainer must hold a paid Apple Developer Program membership to obtain a Developer ID Application certificate.
- Every release requires notarization via `notarytool` before distribution.
- Auto-updates (Sparkle) are deferred to v2. v1 users re-download the DMG manually.
- The privacy statement in Settings must remain literally true: one network call total in v1 (model download), no telemetry, no auto-update check.
